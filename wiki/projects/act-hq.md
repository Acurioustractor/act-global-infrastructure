# ACT Headquarters

Project code `ACT-HQ`. The home for A Curious Tractor's overhead: administration, founder transfers and
shared operating costs that belong to no single project. It keeps those costs out of the projects'
own books, so each project's money shows whether it pays its way.

Added to `config/project-codes.json` on 2026-09-26 from the Supabase `projects` table, where it was
already in use.
